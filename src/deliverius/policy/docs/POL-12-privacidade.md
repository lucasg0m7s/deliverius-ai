# POL-12 · Privacidade e dados pessoais

## Quando se aplica

Sempre que você conversa com o atendimento do Deliverius.

## O que o Deliverius faz

Usamos só os dados necessários para resolver o seu atendimento. Seu nome, documento, telefone, e-mail e endereço
são mascarados antes de qualquer análise automática e nunca aparecem nos registros técnicos.

## Prazo

Os dados do atendimento ficam guardados só pelo tempo necessário para resolver o caso e cumprir obrigações legais.
Você pode pedir acesso, correção ou exclusão dos seus dados a qualquer momento.

## Quando uma pessoa analisa

Pedidos sobre os seus dados pessoais são tratados por uma pessoa da nossa equipe.
